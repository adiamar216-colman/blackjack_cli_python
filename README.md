# Blackjack CLI Game

A command-line Blackjack game built in Python.

This project demonstrates game logic, user interaction, and basic UI design in a command-line environment.

## Features

* Player vs computer gameplay
* Decision-based CPU logic
* Visual ASCII card display
* Persistent statistics using JSON
* Replay functionality

## How to Run

```bash
python blackjack.py
```

## Technologies

* Python
* JSON (file storage)
* CLI (Command Line Interface)
